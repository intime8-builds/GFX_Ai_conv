# GFX Ai Conv Simple Preview

Самостоятельная Windows-программа для подготовки медиа к AI и возврата в Nuke.
Ветка: `codex/simple-ai-converter`. Это отдельный preview: старая программа,
её настройки и канал обновлений не заменяются.

## Быстрый старт

1. Выберите «Для AI» или «В Nuke» и папку результата.
2. Добавьте MOV/MP4, отдельный EXR/PNG или папку последовательности.
3. Проверьте входное цветовое пространство. Для EXR без метаданных ACES2065-1
   является только предположением и требует подтверждения.
4. Нажмите «Старт». Результаты каждого запуска попадают в новую отдельную папку.
   Источники и ранее созданные результаты не перезаписываются.

## Для AI

- Универсальный профиль: H.264 MP4, Rec.709 SDR, 8-bit yuv420p, faststart,
  CPU/x264, CRF 16, medium. Это качественное, но не математически lossless сжатие.
- Совместимый MP4 копируется с проверкой SHA-256; подходящий MOV перепаковывается.
- Пустые поля диапазона, FPS и размера сохраняют исходные параметры.
  Последовательности по умолчанию читаются с 24 fps; для видео берётся его FPS.
- Изменение размера вписывает изображение с полями, без скрытого кадрирования.
  Для yuv420p нечётный край дополняется до чётного, о чём сообщается в результате.
- Можно экспортировать выбранный кадр в PNG 16-bit Output sRGB.
- MP4 не содержит alpha. Сведение на чёрный требует явного подтверждения.
- Несколько последовательностей добавляются отдельными заданиями; пропуски
  блокируют проблемную последовательность, а не заменяются повторением кадров.

## В Nuke

Совместимые MP4, ProRes MOV, PNG и EXR сохраняются без нового сжатия.
Подходящий поток H.264 из MOV перепаковывается в MP4. Для другого видео
нужно явно выбрать декодирование в float EXR. Это не возвращает утраченную
нейросетью детализацию, HDR, alpha или исходную экспозицию.

Рядом создаются `open_in_nuke.nk` и `conversion.json`. Скрипт использует
относительный путь, фактический диапазон и FPS, ACES 1.2, рабочее ACEScg,
Viewer sRGB (ACES). Входной цвет задаётся явно через OCIOColorSpace.
Для Output Rec.709 / Output sRGB применяется обратное Output-преобразование,
а не произвольная gamma. Уже подготовленный SDR не получает повторный RRT/ODT.
VFR, неизвестный цвет и HDR требуют отдельного решения; молчаливой подмены нет.

Через выбор JSON исходного задания можно явно связать возврат с подготовкой.
Эта связь не меняет автоматически размеры, время или цвет возвращённого файла.

## Очередь, настройки и диагностика

«Пауза» действует после текущего задания. «Стоп» отменяет текущую обработку.
Повтор создаёт новое задание; предыдущий результат сохраняется. Незавершённые
файлы остаются во временной папке, готовый результат публикуется только после проверки.

Настройки и журналы: `%LOCALAPPDATA%\GFX Ai Conv Simple Preview`.
Кнопка сбора логов сохраняет диагностический JSON. Он может содержать имена
и пути ваших файлов: проверьте его перед передачей третьим лицам. Кадры не загружаются.
Закрытие окна оставляет приложение в трее; «Выход» в трее завершает его.

Обновления ищутся только среди `simple-v*` GitHub releases. Скачивание и проверка
SHA-256 идут в окне программы; установка требует закрытия и перезапуска процесса,
но не открытия сайта. Сетевая блокировка GitHub не обходится отключением TLS.
В portable-режиме окно обновления предупреждает об установке отдельного Simple
Preview в папку пользователя: старая portable-папка остаётся нетронутой.

## Сборка

На машине разработчика нужны Node.js и Python 3.12. На машине пользователя нет.

```powershell
npm ci
python -m pip install -r backend/simple/requirements.txt
python scripts/prepare-simple.py
npm test
python -m unittest discover -s backend/simple -p "test_*.py"
npm run dist -- --publish never
```

Сборка загружает закреплённую открытую ACES-конфигурацию и проверяет Git blob SHA.
Nuke и его компоненты в поставку не входят. GitHub Actions собирает установщик
и portable ZIP; preview публикуется отдельно и не помечается Latest.
Совместимость с конкретными AI-сервисами в этой версии не заявляется.
