Вопросы и ответы

    

      
Что делают два режима?
«Для AI» подготавливает изображение или видео для AI-сервисов. Это преобразование в SDR, а не обещание сохранения всего исходного диапазона. «В Nuke» подготавливает полученный результат и файл .nk для дальнейшей работы. Для конвертации установленный Nuke не нужен; он понадобится, чтобы открыть .nk.

      
Как выбирается цвет?
Список берётся из реальной конфигурации OCIO ACES 1.2. Для неизвестного EXR предлагается ACES - ACES2065-1, но это не определение цвета файла: выберите верное пространство и явно подтвердите его для каждого задания. Для видео с известными SDR-метаданными возможно автоматическое назначение Output - Rec.709. Неизвестное видео также требует подтверждения. Для HDR-видео SDR-пространство автоматически не назначается: требуется явный выбор и подтверждение цвета источника. Output - sRGB в ACES 1.2 используется для sRGB-вывода; оно не взаимозаменяемо с линейным ACEScg.

      
Как выбрать матрицу YUV и диапазон уровней?
Эти настройки применяются только к видео. В режиме «Авто» backend учитывает метки матрицы и диапазона в файле. Если соответствующие метки отсутствуют, для явно подтверждённого Output - Rec.709 или Output - sRGB используются BT.709 и ограниченный диапазон, с предупреждением backend. Это допущение, а не распознавание источника. Известные матрицу BT.709, BT.601 или BT.2020 и ограниченный либо полный диапазон можно задать вручную до добавления или повтора задания. Уже добавленные задания сохраняют свой снимок настроек.

      
Почему у EXR 24 FPS?
У EXR обычно нет надёжной частоты воспроизведения. По умолчанию используется 24 FPS, её можно изменить до добавления источника в обоих режимах, включая возврат EXR в Nuke. Видео сохраняет известную исходную частоту. Пустой FPS результата сохраняет частоту источника; пустые ширина и высота сохраняют размер. Диапазон задаётся в секундах, обе границы необязательны.

      
Что сохраняется при возврате в Nuke?
По умолчанию сохраняется исходный формат без изменения геометрии или диапазона. MP4 возвращается копией вместе с .nk, а не становится исходным EXR. Альтернативный вариант — конвертация в EXR. Ни EXR-контейнер, ни .nk не восстанавливают потерянные HDR-данные, детали или цвет исходника после AI-обработки. JSON-манифест можно связать с заданием для передачи имеющихся сведений об источнике.

      
Что происходит с альфой?
Если backend обнаружил альфа-канал, экспорт видео для AI заблокирован до явного подтверждения сведения альфы на чёрный фон. Это удаляет прозрачность из видео. Подтверждение относится только к выбранному заданию; исходный файл остаётся нетронутым. При экспорте кадра PNG backend сохраняет альфу, поэтому подтверждение сведения для PNG не требуется.

      
Как получить выбранный кадр PNG?
В режиме «Для AI» выберите «Кадр PNG» для любого источника: видео, последовательности или отдельного изображения. Индекс кадра начинается с 0; для одиночного изображения используется 0. Экспортируется один выбранный кадр, а не вся последовательность или видео в виде набора PNG. Альфа сохраняется.

      
Как обрабатываются папки и пропуски кадров?
Источники определяет backend. Если в папке несколько кандидатов, выберите нужные из полного списка. Кандидат с пропусками кадров заблокирован. Нумерация и состав последовательностей не угадываются интерфейсом.

      
Пауза, остановка и повтор
Пауза дожидается окончания текущего задания. Остановка запрашивает отмену текущей операции; очередь сохраняется. Завершённое, ошибочное или остановленное задание можно повторить: создаётся новое задание с тем же источником и текущими настройками, включая направление. Предыдущее задание и его результат сохраняются, файлы не удаляются. Очистка активной очереди требует подтверждения, затем запрашивает остановку и дожидается её окончания.

      
Изменяются ли исходники и задания в очереди?
Исходные файлы не изменяются. Папка результата запоминается. Настройки сохраняются при изменении и применяются к новым заданиям; уже добавленные задания сохраняют свой снимок настроек. Цвет и согласие на сведение альфы проверяются отдельно для каждого источника. Результаты конвертации сохраняются отдельно; очистка очереди не удаляет файлы.
