    FAQ

    Basic flow

    Choose an output folder, drop files or numbered EXR folders into the queue, then press Start.

    PNG output

    PNG mode exports a 16-bit PNG from the first readable frame using an sRGB-oriented RGB path.

    Video output

    H.264 MP4 mode exports lossless 10-bit H.264 High10 MP4 through CPU x264.

    Duration

    Full duration is enabled by default. Disable it only when a specific duration in seconds is required.

    EXR folders

    Drop a folder with continuous numbered files like shot_0001.exr, shot_0002.exr. The app reads the sequence at 25 fps.

    Queue controls

    Start begins queued jobs. Pause stops after the current job. Stop kills the current FFmpeg process. Clear empties the queue.

    Updates

    Updates are downloaded and installed from the app window. The installer runs silently and the app relaunches after installation.
