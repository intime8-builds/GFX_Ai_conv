    FAQ

    Базовый порядок

    Выберите папку вывода, добавьте файлы или папки с нумерованной EXR-секвенцией, затем нажмите Старт.

    PNG

    Режим PNG сохраняет 16-битный PNG из первого читаемого кадра через sRGB-oriented RGB path. Для статичных файлов это обычная конвертация изображения, для видео берётся первый кадр.

    H.264 MP4

    Режим H.264 MP4 сохраняет lossless 10-bit H.264 High10 MP4 через CPU x264, без звука, с BT.709/sRGB-friendly метаданными цвета.

    ACES2065-1 EXR

    Режим ACES2065-1 EXR пишет half-float OpenEXR. Статичные файлы сохраняются одним .exr, видео и EXR-папки сохраняются как EXR-секвенция в отдельную папку.

    Разрешение

    По умолчанию используется исходное разрешение. Отключите Исходное разрешение и задайте ширину/высоту, если нужен конкретный output size. Для MP4 нечётные значения будут приведены к чётным пикселям.

    Длина

    По умолчанию включена полная длина исходника. Отключите Полная длина только если нужен конкретный хронометраж в секундах.

    EXR-секвенции

    Перетащите папку с непрерывной нумерацией, например shot_0001.exr, shot_0002.exr. Приложение читает EXR-секвенции как 24 fps.

    Очередь

    Старт запускает ожидающие задачи. Пауза остановит очередь после текущего файла. Стоп убивает текущий FFmpeg-процесс. Очистить удаляет все элементы из очереди. Повторить добавляет тот же исходник в конец очереди для новой конвертации.

    Обновления

    Обновления скачиваются и устанавливаются из окна приложения. Установщик запускается тихо, после установки приложение перезапускается.
